# Reserach Project 1

The project exists to consume data bases and evaluate research questions.

## Data Source

Income Support Caseload as reported by Open Data Alberta - https://open.alberta.ca/opendata/income-support-caseload-alberta

 See the larger context of the use of AI in reproducible research in this [slide deck](https://www.linkedin.com/posts/andriy-v-koval_on-the-uses-of-ai-in-reproducible-research-activity-7378565074883485696-yZoZ?utm_source=share&utm_medium=member_desktop&rcm=ACoAAAPuyGkBVynWtdzF2bvfJuen2oYrhDWzu6c).
